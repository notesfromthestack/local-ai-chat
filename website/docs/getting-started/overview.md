# Local AI Assistant

The Local AI Assistant is a locally operated conversational assistant.

It uses:

- A local language model
- Ollama for model execution
- Qdrant for vector search
- A Python API
- Docusaurus documentation
- Retrieval-augmented generation for documentation and local files

## What you will learn

This documentation explains how to:

- Start the assistant with Podman Compose
- Download and configure an Ollama model
- Use the API
- Configure Qdrant
- Add documents for retrieval
- Troubleshoot common problems
- Contribute to the project
